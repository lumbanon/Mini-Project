# RPG Game (C++)

This repository contains a simple RPG game written in C++.

## Description

This is a console-based RPG game where players can choose different character classes such as Warrior, Mage, and Priest.

## Features

- Multiple character classes (Warrior, Mage, Priest)
- Object-oriented design
- Console-based gameplay

## How to Run

1. Compile the program:
g++ main.cpp player.cpp -o rpg
2. Run the program:
./rpg
