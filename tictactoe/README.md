# Tic Tac Toe (C++)

This repository contains a simple Tic Tac Toe game written in C++.

## Description

This is a console-based Tic Tac Toe game written in C++. Two players take turns placing X and O on a 3x3 grid, and the program determines the winner or if the game ends in a draw.

The project demonstrates fundamental programming concepts such as arrays, functions, loops, and input validation, while also showcasing structured game logic and flow control.

## Features

- Two-player turn-based gameplay (X vs O)  
- 3x3 game board displayed in console  
- Win detection (rows, columns, diagonals)  
- Draw detection when board is full  
- Input validation for row and column selection  
- Prevents overwriting occupied cells  
- Clear game loop and modular function design  

## How to Run

1. Compile the program:
```bash
g++ tictactoe.cpp -o tictactoe
```
2. Run the program:
```bash
./tictactoe
```
